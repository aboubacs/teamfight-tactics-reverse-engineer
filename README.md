## About

This project is a complete reverse engineering of Teamfight Tactics as it was in 2021 (Sets 4.5 and 5).

The goal is to simulate fights and gather data in under a second, rather than having to play full 30–40-minute games in the live version.

Champions, movement mechanics, mana generation, shields, damage calculations, projectiles, positioning, items, and synergies are all fully implemented. The achieved goal is: 100% behavior fidelety with the game (rather than UI polishness), as we aim to collect behavioral data only.
